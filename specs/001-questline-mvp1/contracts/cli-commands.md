## 1. ql add

**설명**: 새로운 퀘스트 생성

**사용법**:
```bash
ql add "<제목>" [-d <마감일>]
ql add "<제목>" [--due=<마감일>]
```

**인자**:
| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| title | string | Yes | 퀘스트 제목 (최대 200자) |

**플래그**:
| 이름 | 축약 | 타입 | 기본값 | 설명 |
|------|------|------|--------|------|
| --due | -d | string | - | 마감일 (ISO 8601: YYYY-MM-DD) |

**예제**:
```bash
ql add "코드 리뷰하기"
ql add "문서 작성" -d "2025-03-25"
ql add "버그 수정" --due="2025-12-31"
```

**성공 출력**:
```
✓ 퀘스트 #a1b2c3d4 생성됨: "코드 리뷰하기"
```

**에러 출력**:
| 코드 | 메시지 |
|------|--------|
| ERR_EMPTY_TITLE | ✗ 오류: 퀘스트 제목이 필요합니다. |
| ERR_TITLE_TOO_LONG | ✗ 오류: 제목은 200자 이하여야 합니다. |
| ERR_INVALID_DATE | ✗ 오류: 날짜 형식이 올바르지 않습니다. (YYYY-MM-DD) |

## 2. ql done

**설명**: 퀘스트 완료 처리 및 XP 획득

**사용법**:
```bash
ql done <퀘스트ID>
```

**인자**:
| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| quest-id | string | Yes | 완료할 퀘스트의 ID |

**예제**:
```bash
ql done a1b2c3d4
ql done b2c3d4e5
```

**성공 출력 (레벨업 없음)**:
```
✓ 퀘스트 완료! +50 XP
   다음 레벨까지: 30/150 XP
```

**성공 출력 (레벨업 있음)**:
```
✓ 퀘스트 완료! +50 XP

🎉 레벨업! Lv.1 → Lv.2
   칭호: Junior
   다음 레벨까지: 0/200 XP
```

**에러 출력**:
| 코드 | 메시지 |
|------|--------|
| ERR_QUEST_NOT_FOUND | ✗ 오류: 퀘스트를 찾을 수 없습니다: {id} |
| ERR_QUEST_ALREADY_DONE | ✗ 오류: 이미 완료된 퀘스트입니다. |
| ERR_MISSING_ID | ✗ 오류: 퀘스트 ID가 필요합니다. |

## 3. ql ls

**설명**: 퀘스트 목록 조회

**사용법**:
```bash
ql ls [flags]
```

**플래그**:
| 이름 | 축약 | 타입 | 기본값 | 설명 |
|------|------|------|--------|------|
| --all | -a | bool | false | 모든 퀘스트 표시 |
| --done | -d | bool | false | 완료된 퀘스트만 표시 |

**필터 동작**:
- 기본 (플래그 없음): status = 'TODO'
- --all: 필터 없음
- --done: status = 'DONE'

**예제**:
```bash
ql ls              # 진행 중인 퀘스트만
ql ls -a           # 모든 퀘스트
ql ls --all        # 모든 퀘스트
ql ls -d           # 완료된 퀘스트만
ql ls --done       # 완료된 퀘스트만
```

**출력 형식** (테이블):
```
ID          제목                    상태    마감일
----        ------                  ----    ------
a1b2c3d4    리팩토링하기            TODO    03-25
b2c3d4e5    문서 작성               TODO    03-26
c3d4e5f6    테스트 추가             DONE    03-20
```

**색상 표시**:
- TODO: 노란색
- DONE: 초록색
- DROPPED: 빨간색

**빈 목록 출력**:
```
퀘스트가 없습니다. 'ql add'로 새 퀘스트를 만들어보세요!
```

## 4. ql me

**설명**: 플레이어 상태 조회

**사용법**:
```bash
ql me
```

**출력 형식**:
```
╔══════════════════════════════════╗
║        퀘스트라인 캐릭터         ║
╠══════════════════════════════════╣
║  레벨: Lv.2                      ║
║  칭호: Junior                    ║
║  누적 XP: 150                    ║
║                                  ║
║  다음 레벨까지: 150/200 XP       ║
║  [████████░░░░░░░░░░░░] 75%      ║
║                                  ║
║  완료한 퀘스트: 3개              ║
╚══════════════════════════════════╝
```

**진행 바**:
- 너비: 20 문자
- 채움: █
- 비움: ░

## 5. 칭호 시스템

**레벨별 칭호**:

| 레벨 범위 | 칭호 |
|-----------|------|
| Lv.1~9 | Intern |
| Lv.10~19 | Junior |
| Lv.20~29 | Senior |
| Lv.30~49 | Lead |
| Lv.50~98 | Principal |
| Lv.99~ | Guru |

## 6. 레벨업 시스템

**XP 보상** (MVP1: 모든 퀘스트 고정 50 XP, 난이도 시스템은 MVP2에서 구현 예정)

**레벨업 공식**:
```
다음 레벨 필요 XP = 100 + (현재 레벨 * 50)
```

**예시**:

| 현재 레벨 | 필요 XP | 누적 XP |
|-----------|---------|---------|
| Lv.1 → Lv.2 | 150 | 150 |
| Lv.2 → Lv.3 | 200 | 350 |
| Lv.3 → Lv.4 | 250 | 600 |
| Lv.4 → Lv.5 | 300 | 900 |
